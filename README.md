# 📝 Todo App

A modern, intuitive task management mobile application built with **Flutter**. Designed with a sleek aesthetic and full user-flow features from onboarding to insightful analytics.

---

## 🚀 Features

* **Seamless Onboarding:** Simple, clean user intro and splash sequence.
* **Smart Task Management:** Easily add, track, filter, and complete daily tasks.
* **Interactive Calendar View:** Plan ahead and view scheduled tasks by date.
* **Detailed Statistics & Insights:** Track your weekly productivity, streak count, and task categories.
* **Customization:** Built-in settings including support for dark mode toggles and account preferences.

---

## 🛠️ Tech Stack & Design

* **Framework:** [Flutter](https://flutter.dev)
* **Language:** Dart
* **UI/UX Design:** Custom Figma Mockups & Prototypes
